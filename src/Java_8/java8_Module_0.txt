Why did Java 8 come?

Interview-ready answer:

Java 8 was introduced to modernize Java and make code more concise,
readable, and maintainable. Before Java 8, developers had to write
 a lot of boilerplate code using loops, anonymous inner classes, and
  manual collection processing. Java 8 introduced Functional Programming
   concepts like Lambda Expressions, Functional Interfaces, Stream API,
    Optional, the new Date-Time API, and Default Methods. These features
     simplified collection processing, improved parallel programming
     support, reduced boilerplate code, and helped solve common
 issues like NullPointerException and interface evolution
 ---------------------------------------------------------
 Interviewer: Why was Lambda introduced?
Lambda Expressions were introduced to bring functional programming into Java, allowing behavior to be passed as data.
They also reduce boilerplate code created by anonymous inner classes.
----------------------------------------

Interviewer: Is Java 8 only about Stream API?
no.
Stream API is only one feature. Java 8 also introduced Lambda Expressions, Functional Interfaces, Method References, Optional, the new Date-Time API, Default Methods,
 Static Methods in interfaces, CompletableFuture, and more
-----------------------------------------------------------
Java 8 is not just "Lambda and Streams."
It introduced Functional Programming concepts into Java.
The biggest change is thinking in terms of what to do instead of how to do it.
Streams do not store data; they process data from a source like a collection.
Java 8 was designed to reduce boilerplate code, improve readability, support multicore processors,
and make APIs easier to evolve.
