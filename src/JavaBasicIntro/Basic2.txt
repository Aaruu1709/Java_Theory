✅ Java Compilation & Execution – Interview Answer

Step 1:
Write Java program and save it with .java extension

Step 2:
Compile using Java compiler

javac FileName.java


Step 3:
Compiler checks syntax & semantic errors

If errors → compilation fails

If no errors → .class file(s) generated

Step 4:
.class file contains bytecode, which is platform-independent

Step 5:
Run the program using JVM

java ClassName


Step 6:
JVM loads the class using Class Loader

Step 7:
JVM verifies bytecode for security and correctness

Step 8:
Execution Engine (Interpreter + JIT) converts bytecode to machine code

Step 9:
JVM finds and executes

public static void main(String[] args)


Step 10:
Program runs and output is displayed

Java achieves platform independence by compiling
source code into bytecode, which is executed by the JVM.
